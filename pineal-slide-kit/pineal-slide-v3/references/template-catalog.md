# テンプレ同梱スライドのカタログ

`assets/pineal_temp.pptx` には16枚の実例スライドが入っている。
**ゼロから図を組む前に、必ずこのカタログで近い型を探し、それを複製して中身を差し替える。**
座標・配色・余白がテーマに合った状態から始められるため、目視QAでの手戻りが激減する。

|---:|---|---|

| 2 | アジェンダ（右カラムに項目） | 目次 |

| 4 | （公開版では中身を外してある） | 使わない |
| 5 | （公開版では中身を外してある） | 使わない |

## 複製のやり方

同一プレゼン内での複製ではなく、**テンプレから1枚だけ取り出して新規pptxにする**。
`scripts/new_slide.py` がこれを行う。

```bash
python3 scripts/new_slide.py --template assets/pineal_temp.pptx \
    --source-slide 8 --out "S03_プロジェクト理解/S03_プロジェクト理解.pptx"
```

`--source-slide` は上表の番号（1始まり）。省略時は 8（中面の素）。

## 型が無いとき

無理に既存の型をねじ曲げるより、**8番（中面の素）にボディを自作**したほうが速くて綺麗。
その場合は `design-system.md` の定位置とサイズ階層に従う。
