## フォント

```
majorFont: 游ゴシック Light   （見出し）
minorFont: 游ゴシック         （本文）
```

明示指定せずテーマ継承に任せるのが原則。日本語フォント名を直書きすると環境差で崩れる。

**⚠️ ただしデッキごとに実態が違う。** 案件デッキは Noto Sans JP で組まれ、しかも
master/layout に直書きされていることがある。**作業前に必ず現状を確認する。**

```bash
python3 scripts/set_font.py inspect --file deck.pptx
```

フォントを差し替える場合は `scripts/set_font.py font`（全パート対象）。
テーマだけ変えても効かない → `pitfalls.md` の「0. フォントはテーマだけ変えても効かない」

### 中面A の標準（2026-09 確定）

`assets/pineal_temp.pptx` の `中面A` レイアウトに反映済み。**新規スライドは自動でこの形になる。**

| 項目 | 値 |
|---|---|
| タイトル サイズ | **28pt**（旧 20pt） |
| タイトル 位置・高さ | **top 0.346 / height 0.471**（28ptに合わせて上に拡張） |
| リード文の行頭 | **✓ の箇条書き**（Wingdings の `ü`） |
| リード文のインデント | `marL="285750" indent="-285750"`（ハンギング） |

リード文のチェックマークはレイアウトの `subTitle` → `lvl1pPr` に設定してあるため、
**個別スライドで何もしなくても付く**。外したい特定ページだけ `<a:buNone/>` を入れる。

既存デッキに後から適用する場合は `scripts/apply_standard.py` を使う。

```bash
python3 scripts/apply_standard.py --file deck.pptx            # 中面A の全ページに適用
python3 scripts/apply_standard.py --file deck.pptx --dry-run  # 対象ページの確認のみ
```

タイトル・メッセージラインは**プレースホルダー**で、サイズ・色をレイアウトから継承する。
`font.size` は `inherit`（None）のまま触らないこと（→ `pitfalls.md`）。

## フォントサイズの階層

### 固定ポイント（全ページ・全デッキで必ず同じ値にする）

ページごとに変えないこと。**揃っていないと資料全体が素人っぽく見える。**

| 用途 | pt | bold | 備考 |
|---|---:|---|---|
| **タイトル** | **28** | ✓ | レイアウト `中面A` の ctrTitle で継承。個別に触らない |
| **リード文（メッセージライン）** | **18** | — | 同 subTitle で継承。行頭に ✓ |
| **セクション見出し**（赤い罫線の上のラベル） | **14** | ✓ | 2026-09 に 11 → 14 へ変更 |
| **脚注** | **8** | — | y=6.72 |

タイトルとリード文はレイアウトから継承されるので、**新規スライドでは何もしなくてよい**。
セクション見出しと脚注は図形で作るため、上の値を明示指定する。

### 可変（コンテンツの密度に応じて調整してよい）

情報量が多い表組みのページでは下げる。ただし**同一ページ内では階層を守る**。

| 用途 | pt | bold |
|---|---:|---|
| 箱のタイトル | 9.5〜11 | ✓ |
| 箱の本文 | 7.5〜8.5 | — |
| 箱の補足（グレー） | 7.5 | — |
| 数値の強調 | 8.5〜9.5 | ✓ |
| テーブル名等の極小注記 | 6.5 | — |

## 図の基本文法

- **箱** = 角丸長方形（`MSO_SHAPE.ROUNDED_RECTANGLE`）／ 白地＋`D9D9D9`枠
- **強調する箱** = 赤薄地＋`D21E2C`枠
- **矢印** = 小さな三角または細長長方形。`D21E2C` か `939292`
- **バンド** = 直角長方形（`RECTANGLE`）／ `F6F3F3` 地・枠なし
- **既存 vs 追加** を示すときは グレー＝既存 ／ 赤＝今回追加 で塗り分け、その凡例をセクション見出しに書く
