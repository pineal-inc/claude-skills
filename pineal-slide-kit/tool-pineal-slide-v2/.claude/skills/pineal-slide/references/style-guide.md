# Pineal Style Guide v2

このドキュメントは Pineal Slide v2 のデザインルールを集約したものです。
スライド生成時に必ず参照してください。

> **v1 からの変更点**: フォント Arial 統一、カラートークン変更、サイズ単位 pt 統一

---

## 1. カラーパレット

| トークン | HEX | 用途 |
|---------|------|------|
| `--c-primary` | `#D21E2C` | 見出しアクセント、ブランドカラー |
| `--c-primary-dark` | `#A01423` | ダーク赤（現行テンプレートでの既定用途はなし。赤系の閉じた列挙の一員） |
| `--c-primary-light` | `#F1E5E5` | 背景ハイライト、After カード |
| `--c-accent-gold` | `#C8A064` | ゴールドアクセント |
| `--c-text` | `#1C1A1A` | 本文テキスト |
| `--c-text-muted` | `#939292` | 補足テキスト、サブタイトル |
| `--c-bg` | `#FFFFFF` | スライド背景 |
| `--c-surface` | `#F6F3F3` | カード背景、表面 |
| `--c-subtle` | `#6B7180` | 控えめグレー |
| `--c-dark-bg` | `#1C1A1A` | ダークスライド背景 |

### カラールール（基調は白＋ダーク＋グレー。赤はオプトイン）

> **適用範囲**: 本節は `pineal-slide` / `pineal-validate` と
> `templates/pineal-v2.css` を使う成果物（PPTX 変換前提のスライド）の配色正本。
> `figure-templates.md` に直値で書かれている色も本節の値である。
> 文体（R1〜R6）と「表記の共通ルール」は `~/.claude/rules/document-tone-rules.md` が正本。
- **赤（#D21E2C）の既定はブランド要素のみ**: ヘッダー下の1pt罫線、h1左のアクセントバー（ダーク面含む）。それ以外の赤はすべて意図的なオプトイン
- **「赤系」は閉じた列挙**: `#D21E2C`（Primary）・`#A01423`（Primary Dark）・`rgba(210,30,44,*)` の3つ。この列挙以外の赤（例 `#8e0000`）はパレット外であり使わない。検査もこの列挙に対して行う
- **強調は必須ではない。赤ゼロのスライドが標準**。タイムテーブル・一覧表・説明スライドなどは強調なしでよい
- 本文中の赤強調を入れる場合は**1スライド最大1箇所**、かつ「読者の意思決定に直結する数字・行・結論」に限る。デッキ全体でも本当に立てたい数箇所まで
- 装飾目的の赤は禁止: カード見出し（h3）・KPI数値・罫線・バッジ・番号丸・矢印・タグは `#1C1A1A`（ダーク）または `#939292`（グレー）を使う
- ベタ塗りの強調帯（result-strip等）はダーク `#1C1A1A`。赤ベタ帯は使わない
- 行ハイライトは淡背景 `#F1E5E5` まで。赤文字＋赤枠＋淡背景の多重使用はしない
- Before/問題 → グレー系（`#f5f5f5` + `#9e9e9e`）、After/解決 → 淡背景 `#F1E5E5`（赤枠・赤文字は重ねない）
- ダーク背景（タイトル/セクション/CTA）は `#1C1A1A`
- テキストの背景コントラスト比は**4.5:1以上**を確保
- **グラデーション不可**（html2pptx 非対応）
- ボックスの色分けをするなら**同一スライドに凡例を置く**。色の意味を図の外に置き去りにしない
- カテゴリ色のパレットには**グレー（モノトーン）を含める**。全カテゴリを有彩色で塗り分けない
  （出典: consulting-pptx-skill slide-rules 突合 2026-09-03。対応表 `~/.claude/skills/verify/references/consulting-pptx-skill-mapping-2026-09-03.md`）

## 2. タイポグラフィ

### フォントスタック
- **唯一のフォント**: `Arial, Helvetica, sans-serif`
- Roboto / Noto Sans JP は使用不可（PPTX 互換のため）

### 階層

| レベル | サイズ | ウェイト | 色 | 役割 |
|--------|--------|---------|-----|------|
| h1 | 20pt | 700 | Text | スライドの見出し（文体条件は正本）。1行に収める目安は**全角24字以内**（PPTX 変換後の折り返し余裕込み） |
| h1（ダーク） | 28pt | 700 | White | タイトル/セクションスライド |
| .lead | 12pt | 400 | Text | このスライドの結論。件数と契約は Phase 0 |
| h2 | 12pt | 500 | Muted | 文脈の補足（下線は `<div class="h2-line">` で別途追加） |
| h3 | 10pt | 700 | Text | カード内見出し（赤にしない） |
| 本文 | 9pt | 400 | Text | 証拠・詳細 |
| stat-num | 28pt | 900 | Text | **legacy 専用。新規では使わない** |

**基準本文級数は 9pt**（上の表の「本文」）。正本 `~/.claude/rules/document-tone-rules.md`「表記の共通ルール」の
数字の項が参照する分母はこの値であり、`templates/pineal-v2.css` の `body` の継承値ではない。判定手順は正本が持つ。

### タイポグラフィルール

> **文体の正本（必読）** → `~/.claude/rules/document-tone-rules.md`
> h1 / h2 / h3 / h4 は同ファイルの R1〜R4、本文と `.lead` は R5〜R6 の判定対象。
> ここには規範文を再掲しない（再掲すると片側だけ更新されて矛盾するため）。

- 見出し（h1〜h4・表のヘッダー）と本文の文体条件は正本が定義する。ここには再掲しない
- `.lead` の契約（件数・文数・字数・行数・タグ）は `pineal-validate/skill.md` の Phase 0 が定義する
- 太字の多用禁止。1スライドの太字は見出し + 1-2箇所まで
- **テキストは意味タグのみに記述**: `<p>`, `<h1>`〜`<h6>`, `<ul>`, `<ol>`
- `<div>` に直接テキストを入れない（html2pptx がテキストとして認識しない）

## 3. スペーシング

### スライド全体（720pt x 405pt）
- パディング: 上 `48pt`（header 36pt 含む） / 左右 `48pt` / 下 `32pt`
- ヘッダー高さ: `36pt`（48ptは広すぎるので使わない）
- ダークスライド: 左右 `64pt`、**垂直方向**のみ中央（`justify-content: center`）。水平方向は左揃え

### コンポーネント間
- grid-2 gap: `24pt`
- grid-3 gap: `16pt`
- grid-4 gap: `12pt`
- カード内パディング: `16pt`
- 要素間マージン: `8-12pt`

### スペーシングルール
- 余白はケチらない。「何もない空間」が視線を誘導する
- 要素が多いほど gap を小さくして収める
- **水平方向は左揃えが基本**。`text-align: center` を使ってよいのは、
  幅の狭いセル内のラベル・数値（比較表のヘッダーとセル、図形内のキャプション、数値カード）に限る
- 表紙・章扉・CTA は**スライド全体としては左揃え**にする。ダーク面で中央に寄せるのは垂直方向だけ
  （CTA の完成形は `pineal-slide/SKILL.md` の CTA テンプレートが正本）

## 4. 情報密度

### 目安（720pt x 405pt スライド）

| 要素 | 最大量 |
|------|-------|
| テキスト | 150文字/スライド |
| 箇条書き | 5項目、1項目30文字以内 |
| カード | 3枚（grid-3）、各80文字以内 |
| 数値 | 見せ方は正本「表記の共通ルール」による（`.dashboard` は legacy 専用） |
| タグ | 6個/グループ |
| テスティモニアル | 3件/スライド |

### 密度が高すぎる場合
1. 枚数を増やす（1枚を2枚に分割）
2. h2 で補足し本文を削減
3. 詳細は `<small>` で小さく添える
4. 図に置き換える（テキスト → ビジュアル）

## 5. コンポーネント選択基準

### 情報の型 → コンポーネント

| 情報の型 | 推奨コンポーネント |
|----------|------------------|
| A vs B の比較（同一対象の before/after） | `.card.before` + `.card.after` |
| 複数対象 x 複数観点の比較 | `<table>`（行=項目・列=観点。左端の軸は大カテゴリで束ねる `rowspan`） |
| ステップ x 手段の組み合わせ | `<table>`（カード羅列や左右2箱の見比べにしない） |
| 並列する特徴 x2 | `.grid-2` + `.card.feature` |
| 並列する特徴 x3 | `.grid-3` + `.card.feature` |
| 並列する特徴 x4 | `.grid-4` + `.numbered-card` |
| 時系列・手順 | `.flow-container` or `.timeline` |
| 数値・KPI | 見せ方は正本「表記の共通ルール」による（`.dashboard` は legacy 専用） |
| 量的比較 | `.bar-chart` or `.bubble-compare` |
| 金額比較 | `.bubble-compare` |
| テキスト中心の引用 | `.testimonial` |
| 複数の顧客の声 | `.testimonial` x N |
| 人物別の事例 | `.grid-2` + `.case-study` |
| 画像+説明 | `.grid-2`（テキスト + 画像プレースホルダー）|
| 写真ギャラリー | `.gallery` |
| 表形式データ | `<table>` with inline style |
| カテゴリ分類 | `.tags` |
| 機能一覧 | `.icon-grid` |
| 概要（複数セクション） | `.multi-section` |
| 結果の強調 | `.result-strip` |
| 数値の強調 | 見せ方は正本「表記の共通ルール」による |

**複数対象 x 複数観点、ステップ x 手段の判断基準**: カード羅列（3枚グリッド）や左右2箱の見比べでは、
比較の軸（観点）が読み手の中で暗黙のままになる。行=項目・列=観点の軸を持つ表にし、
項目数が多いときは左端の軸を大カテゴリで `rowspan` して束ねる。
ただし同一対象の時系列変化（before/after）は対象が1つで軸を要さないため、
従来どおり `.card.before` / `.card.after` でよい
（出典: consulting-pptx-skill slide-rules 突合 2026-09-03。対応表 `~/.claude/skills/verify/references/consulting-pptx-skill-mapping-2026-09-03.md`）。

### スライド種別 → テンプレート

ルート要素には必ず `data-slide-type` と `data-contract-version="pineal-v2.1"` を付ける。
`data-slide-type` が種別判定の正本であり、`pineal-validate` はこの属性で判定する
（属性が無いスライドは v2.0 以前のレガシーとして扱い、警告のみで Fail にしない）。

| スライド種別 | `data-slide-type` | 構造 |
|-------------|------------------|------|
| 表紙 | `cover` | `.slide-dark.title-slide` |
| 章区切り | `section` | `.slide-dark.section-divider` |
| CTA | `cta` | `.slide-dark.cta-slide` |
| 目次 | `toc` | `.slide` + `.agenda` |
| 通常コンテンツ | `content` | `.slide` + `.header` |

クラスは `.slide-dark.title-slide` のように**同一要素に併記**する（子孫ではない）。
種別ごとの `p.lead` の件数と、契約違反の判定条件は
`pineal-validate/skill.md` の Phase 0 が定義する。ここには再掲しない。

## 6. 読み手に求める理解・判断・実行

「何を感じさせるか」ではなく、**そのスライドを読んだ人が何を理解し、何を判断し、何を実行すべきか**で
コンポーネントを選ぶ。本文の文体は正本 R5・R6 による（条件はここに再掲しない）。

| スライドの役割 | 読み手に求めるもの | コンポーネント |
|------|---------|-------------|
| 現状・課題の提示 | 現状と課題の差分を理解する | `.card.before` / `.card.after` |
| 対応方針の提示 | 提案内容を理解する | `.card.feature` / `.numbered-card` |
| 実績・事例の提示 | 実現可能性を事実で確認する | `<table>` / `.case-study` / `.testimonial` |
| 次の手順の提示 | 誰がいつ何をするかを判断する | `.flow-container` / `.cta-slide` |
| 表紙 | 資料の主題と対象を把握する | `.slide-dark.title-slide` |
| 章区切り | 話題の切り替わりを把握する | `.slide-dark.section-divider` |

## 7. レイアウトの禁止事項

- 1スライドに3種類以上の異なるコンポーネントを混在させない
- grid-3 のカードに100文字以上入れない
- 画像と表を同じスライドに配置しない
- **1スライドに表は1つまで**。カード群の下に表を積まない
- 図があるスライドは**左=図・事実、右=意味合い（So What）の2カラム**とする。
  最下部の帯（GOAL/KEY/POINT 等のメッセージボックス）に結論を置かない。結論は `.lead` に書く
- **目次は1列**
- セクションディバイダーにコンテンツを詰めない（完成形は `pineal-slide/SKILL.md` のテンプレート）
- タイトルスライドで箇条書きを使わない
- CSS `display: grid` を使わない（`flex` のみ）
- `::before` / `::after` 疑似要素を使わない
- `linear-gradient` / `radial-gradient` を使わない
- `<div>` にテキストを直接入れない（必ず `<p>` 等で囲む）
- `<h2>` の下線は `border-bottom` ではなく `<div class="h2-line"></div>` を使う
- `<table>` / `<tr>` / `<th>` / `<td>` に background/border を使わない → div+flex で擬似テーブルを構築
- `transform`（`rotate` / `translate` / `scale` / `skew`）を使わない。図形は回転値が PPTX に渡らず軸並行の矩形になる。回転・角度を持つ図形自体を作らない（`border-radius` の四分円も代用にならない。互換ルール8）
- クリッピングに依存した図形を作らない。`clip:rect()` / `clip-path` / `overflow:hidden` の
  可否は用途で3区分され、許可セレクタは閉じたリストになっている。
  条件の正本は `pineal-slide/SKILL.md`「html2pptx 互換ルール（必須）」9（ここに再掲しない）
- CSS三角形（border transparent trick）を使わない
- 丸ボタン+▶ アイコンも使わない（再生ボタンに見える）
- **矢印はテキストで書く**: `<p style="font-size:14pt;color:#939292;font-weight:900;flex-shrink:0;">→</p>`（使える字体と色は互換ルール11）

上記のうち「1スライドに表は1つまで」「左=図・右=So What の2カラム」「目次は1列」は
consulting-pptx-skill slide-rules 突合 2026-09-03 に基づく追記
（対応表 `~/.claude/skills/verify/references/consulting-pptx-skill-mapping-2026-09-03.md`）。
