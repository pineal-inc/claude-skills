# スライドレシピ（頻出スライド型の組み合わせ定義）

制定 2026-08-25。figure-v2 の刷新（方向C）にあわせて新設。
頻出するスライド型を「見出し + リード + 図テンプレート」の組み合わせとして定義する。
フルスライドのテンプレートは持たない（レイアウトの正本は components.md、図の正本は
同じフォルダの `figure-templates.md`。このファイルは両者の組み合わせだけを定める）。

各レシピの見出し・リードは文体ルール（`~/.claude/rules/document-tone-rules.md`）の判定対象。
可用高（h2 あり 230.8pt / h2 なし 265pt）は components.md の値に従う。

## 使い方

1. スライド構成の設計時（Phase 2）に、扱う内容が上表のいずれかに当たるかを確認する
2. 当たる場合はレシピの図テンプレ番号のテンプレートを `figure-templates.md` から取る
3. 見出しは主題ラベル（名詞句）、結論はリードに書く。図の強調1点とリードの結論を必ず一致させる
4. 表にないスライド型は従来どおり components.md から自由に組む（レシピは追加を妨げない）
5. どのレシピでも components.md「本文エリアの占有規律」に従う。図は本文エリアを埋め、
   全幅1図なら幅90%以上・可用高70%以上。満たせなければ左右2分割かスライド分割で図を大きく保つ

### 左右2分割の補足

根拠（図・数値）を左、解釈（言語情報）を右に置く。実務標準の調査（2026-08-25）で
最頻出だった「左グラフ・右メッセージ」型。図とテキストが同居するスライドでは
図を全幅に細く敷くより、片側に全面占有させたほうが図が浮かない。

## 章・軸の一貫運用

冒頭スライド（目次・章扉）で立てた軸（区分・番号・名称）は、後続スライドで**同じ番号・名称のまま**運ぶ。
途中で言い換えたり番号を振り直したりしない。

- ディープダイブのスライド（個別区分を深掘りするスライド）は、**右上に全区分のタグチップを常設**し、
  該当する区分だけを濃色反転して現在地を示す。実装は `.tags`（components.md 14番）の
  タグ群を右上に配置し、該当タグにだけ `primary`（濃色）を当て、他は `outline` / `muted` にする。
  html2pptx で再現できる単純な矩形+テキストの範囲で組む（回転・クリッピングは使わない。互換ルール8・9）
- 工程番号（Step 1 等）は**タイトル文字列に連結しない**。タグチップ（上記）または
  セクションディバイダーの `.section-num`（components.md 12番）で表現する
- 番号・記号は、後続スライドで実際に参照するときだけ導入する。参照されない番号は付けない

## レシピの追加方法

頻出と分かったスライド型を上表に1行追加する。条件は次の2つ:
- 使う図テンプレが figure-templates.md に存在すること（なければ先にテンプレを追加する）
- 見出し・リードの型が文体ルールの R1〜R4 を通ること
