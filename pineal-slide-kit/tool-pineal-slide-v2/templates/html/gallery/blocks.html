A-01 ページのクロム

タイトル・罫・リード・マーク・フッター

v3 の中面Aの定位置をそのまま持ってきた層。ここは触らずに中身だけ差し替える。

構造

  • <header class="slide-head rule"> … 灰の全幅罫＋左91pxの赤罫
  • .kicker … 章番号と section 名（赤・0.18em）
  • .title … 32px / 700。結論ではなく主題を名指しする
  • .lead … 19px。そのページで言い切る一文をここに書く
  • .lead.check … 行頭に ✓（v3 のリード表現）
  • <span class="mark"> … 右上の pineal マーク
  • <footer class="slide-foot"> … 左ロゴ／右メタ

v3 からの実測値

キャンバス
1280 × 720 px（13.333 × 7.5 in）
左右の余白
58px（v3 0.60in = 57.8px）
タイトル上端
30px（v3 33.2px）
罫の位置
y ≒ 88px（v3 87.7px）
赤罫の幅
91px（v3 91.4px）
マーク
右上 y=43px / 27px 高（v3 26.3px）

PPTX の 7.5〜9.5pt という級数は Web には小さすぎるため、本文は 15px を基準にした。

A-02 箱

カードとバンド

部品の見た目を比較するカタログ。実際の資料では同列の項目を揃え、状態や判断の違いがある場合だけ強調する。

DEFAULT

.card

白地＋#D9D9D9 の枠。角丸8px。

ACCENT

.card.accent

明示された選択・判定対象に使う。キーワードという理由では塗らない。

SOFT

.card.soft

淡色地 #F6F3F3・枠なし。

DARK

.card.dark

濃灰地。黒ベタも強調なので、周囲との差に理由がある場合に使う。

.card.top-red

上辺だけ赤。注意すべき条件など、差を示す理由がある場合に使う。

.card.pad-sm

詰めたいとき。.pad-lg もある。

.card.flat

枠も余白も外した素の縦積み。

BAND
枠のない淡色の帯。.band.red / .band.dark。v3 の bg2 バンドに対応する。
部品カタログ ／ 02
A-03 文

メッセージ・引用・注意書き・インライン強調

長い文章を置くページでは、箱に詰めずに文のまま置いたほうが読める。

.msg.lg ／ 左のダークの縦線だけで区切る。長文の段落を並べるときはこれが軽い。
.msg ／ 本文サイズ。段落を続けて置ける。
.msg.plain ／ 線を灰色にした控えめ版。
.callout ／ 灰の淡い面で前提や制約条件を分ける。
.callout.soft ／ 灰の控えめ版。
.quote ／ 現場の声をそのまま置く。— 製造部 ご担当者

インライン

太字／.em 赤太字／.marker 黄マーカー／.marker-red／1,234（.num は等幅数字）

ここは強調方法の見本。外しても読み取りが変わらない強調は使わない。

.footnote.rule ／ 脚注。出典・前提を1〜2行で。

A-05 表

表とその崩し方

条件・料金・比較は表にする。同列の行は揃え、選択・判定対象を明示する場合だけ .hi を使う。

.tbl
区分内容人日金額
要件整理現場ヒアリングと業務の棚卸し8640,000
実装ツール開発と既存システムとの接続241,920,000
定着操作説明と運用ルールの整備6480,000

セルに2文以上を流し込まない。長くなるならセル内を箇条書きにするか行を分ける。

.tbl.compact ／ .tbl.lines
観点現行提案
入力Excel を各自が管理1つの入力画面に集約
共有メール添付更新のたびに全員が同じ版を見る
検索ファイル名頼り本文と添付を横断して検索
引き継ぎ担当者の記憶案件ページに履歴が残る

.compact は級数を1段下げ、.lines は縦罫を消す。密度が高いページ向け。

部品カタログ ／ 05
A-06 比較とフロー

As-Is / To-Be と工程

比較と工程の構成例。同列の項目は同じ見た目にする。変更後や最後の工程という理由で色を足さない。

.compare
AS-IS
担当者ごとに Excel を持ち、更新のたびにメールで配る。
TO-BE
1つの案件ページを全員が見る。更新は履歴として残る。
.flow
STEP 1
現場を見る
実際の作業を横で観察し、詰まっている箇所を特定する。
STEP 2
試作を出す
2週間で動くものを出し、現場に触ってもらう。
STEP 3
運用に載せる
操作説明と運用ルールを整え、担当者に引き渡す。

縦に積みたいときは .flow.vertical。矢印の向きも変わる。
